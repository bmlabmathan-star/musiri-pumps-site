# Musiri Pumps website

A responsive, single-page product and enquiry website based on the supplied HTML concept.

## Preview

Open `index.html` in a browser. The pump finder and application selector run in the browser. The enquiry form opens the visitor's email app; it does not submit to a server.

## Before publishing

Confirm that `sales@musiripumps.com` is the correct enquiry address. Add the business phone, WhatsApp number, full address, verified product models and specifications, and any company history or service coverage you want shown. Product descriptions currently use broad pump categories from the supplied concept.
